01 / Concept

什么是 Vibe Coding

伴随生成式 AI 兴起的一种新型开发方式：不再逐行手写代码，而是用自然语言描述想要的效果、交互与氛围。

由 AI（如 Cursor、Bolt、Lovable、Claude 等）生成并迭代代码，开发者负责把方向、挑审美、调细节，像"调氛围"一样把产品打磨到满意为止。

它把开发者的精力从重复的样板代码，转移到创意、审美与体验决策上。你只需要说清楚"我要一个玻璃拟态的登录卡片，悬停时有渐变光晕"，剩下的 HTML / CSS / React 交给 AI 生成，再用组件库和动效库做锦上添花。

自然语言替代样板代码
组件库拉开质感差距
几轮即可收敛到满意
描述意图，
而非实现细节

风格关键词越具体越好——glassmorphism（玻璃拟态）、neumorphism（新拟态）、gradient（渐变）、dark mode（暗色模式）、3D、微交互。这些正是 Uiverse 等站点沉淀下来的通用风格标签，AI 对其理解度高。

02 / Workflow

核心工作流：四步闭环

把目标拆成"页面结构 + 视觉风格 + 交互动效"三层，然后进入迭代循环。

STEP 01

用自然语言描述意图

页面结构 + 视觉风格 + 交互动效三层拆开描述，直接引用具体风格关键词。

Prompt
STEP 02

让 AI 生成初版并跑起来

此阶段追求"能跑起来、大致像"，不纠结像素级细节，先得到可预览的骨架。

Run
STEP 03

组件库与动效库增强

要现成的按钮、卡片、表单、加载态，去 Uiverse / Aceternity UI / React Bits 直接复制；复杂动效交给 Anime.js。这是拉开质感差距的关键一步。

Enhance
STEP 04

对照设计灵感反复微调

以 Dribbble、MotionSites 上的优秀案例作为审美参照，对照着微调配色、间距与动效节奏。

Refine
迭代循环：看效果 → 说一句 → AI 改 → 再看通常几轮即可收敛

05 / Prompt & Pitfalls

高效提示词要点与避坑建议

要点是"分层 + 具体 + 可对照"：先给整体风格与目标用户，再分模块描述结构、配色、字体与动效。

要做的事

  • ＋
    分层描述整体风格 → 目标用户 → 结构 / 配色 / 字体 / 动效，逐模块展开。
  • ＋
    引用风格关键词直接写 glassmorphism、dark mode、3D，或直接贴参考链接与截图。
  • ＋
    一次只迭代一个明确目标便于 AI 精准改动，也便于你验证效果。

要避的坑

  • ！
    别一次塞入过多冲突要求会让 AI 顾此失彼。
  • ！
    别忽视性能3D 与重型动效要按需引入，注意移动端体验。
  • ！
    别盲信生成代码关键交互与无障碍（对比度、键盘可达）需人工复核。
  • ！
    别把组件库当黑盒与设计不符时回到组件源码微调，才能真正调出自己的氛围。
